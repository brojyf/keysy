# Keysy dashboard mockups

Open `dashboard.html` directly in a browser. No install or build is needed.
The optional Google Fonts stylesheet falls back to system fonts offline.

- **Workspace**: sidebar, credential list, pinned file and recent activity.
- **Command**: horizontal navigation and a compact console layout.
- **Cabinet**: editorial header and a card-based credential library.
- **Palettes**: Jade, Cobalt, Iris, Sandstone, Midnight and Graphite.

Use the top bar to compare layouts and palettes. Search, type filters,
collections, favorites, list/card views and detail dialogs are interactive.
Press `/` to search and `Escape` to close a dialog.

All credentials and identities are fictional. The add form only previews a
confirmation; it does not accept secret values, upload files or save records.
These screens explore visual design, not an approved product architecture.

Organization references: [Infisical](https://infisical.com/videos/secrets-management-infisical)
and [1Password](https://1password.com/developers/secrets-management).
