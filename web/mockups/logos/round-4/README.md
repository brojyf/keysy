15 and 18 are the preferred candidates for refinement. 15 is more explicitly
technical; 18 is more understated. These are design judgments, not a final choice.

## Reference translated into design

- [PORTO ROCHA / Hiro](https://www.portorocha.com/hiro): learn from the use of
  familiar developer notation to express the product. 15 uses a concealed-value
  metaphor in braces; Hiro's mark and lettering are not reused.
- [Order / Crux](https://order.design/project/crux): learn from reducing a
  business-specific idea to one recognizable symbol. Each study uses one motif
  rather than combining a key, lock, access path and storage diagram.
- [Logosystem / Minimal](https://logosystem.co/logos/minimal): use as a comparison
  index for silhouette economy and monochrome balance, not a source of copied art.

The shapes are purpose-built vector paths. The lettering uses the named fonts;
it is not presented as a custom-designed typeface. These metaphors describe the
product category, not additional implemented Keysy capabilities.

## Files and checks

Each direction includes a full outlined SVG and a separate `*-symbol.svg`.
Visible fills and strokes use `currentColor`; the same files recolor across the
existing four paired palettes. Text remains editable in Figma, and SVG exports
need no installed fonts, network fonts or raster assets.

The Figma board and HTML show positive/reverse lockups, 28px-high lockups and
16/24/32px standalone symbols. The braces in 15 have additional internal room
so their rounded strokes are not clipped. Runtime verification covers palette
switching and the continued exclusion of rejected options. These checks do not
establish trademark availability or recognition in a user study.
