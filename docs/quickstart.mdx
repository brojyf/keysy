## Clone the repository

```bash
git clone https://github.com/brojyf/keysy.git
cd keysy
```

Run each section below from the repository root in a separate terminal.

## Run the web app

Install [Bun](https://bun.sh/docs/installation) and Node.js `22.12.0` or later.

```bash
cd web
bun install --frozen-lockfile
bun run dev
```

Open the local URL printed by Vite. You should see the React starter page.

To check the web build:

```bash
bun run build
```

## Inspect the CLI

Install the Go version declared in `cli/go.mod` (currently `1.27.2`).

```bash
cd cli
go run . --help
```

You should see the Cobra scaffold's help output. Product commands are not
implemented yet.

## Preview the documentation

Install Node.js `20.17.0` or later and the
[Mintlify CLI](https://www.mintlify.com/docs/cli/install).

```bash
npm install -g mint
cd docs
mint dev
```

Open `http://localhost:3000`. Edit the MDX pages to update the preview.

Before submitting documentation changes, run these checks from `docs/`:

```bash
mint validate
mint broken-links --check-anchors
```

<Note>
  The API, authentication, and notification service directories are placeholders.
  There is no backend startup command or end-to-end setup yet.
</Note>
