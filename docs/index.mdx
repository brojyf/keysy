Keysy uses a **monorepo**: the web app, CLI, service directories, API contracts,
and infrastructure files live in a single Git repository.

## Repository structure

| Directory | Purpose |
| --- | --- |
| `docs/` | Sourcey documentation and site configuration. |
| `api/` | Reserved for the application API service. |
| `auth/` | Reserved for the authentication service. |
| `notify/` | Reserved for the notification service. |
| `cli/` | Go CLI, built with Cobra. |
| `web/` | React and TypeScript web app, built with Vite. |
| `bot/` | Reserved for the Discord bot. |
| `extension/` | Reserved for the Chrome extension in `chrome/`. |
| `landing/` | Reserved for the landing page. |
| `sdk/` | Reserved for Go and TypeScript SDKs. |
| `help/` | Reserved for help content. |
| `skills/` | Reserved for skills. |
| `openapi/` | Shared OpenAPI definitions for the API and authentication services. |
| `deploy/` | Deployment configuration. |
| `otel/` | OpenTelemetry Collector Docker image definition. |
| `supabase/` | Reserved for Supabase configuration. |
| `.github/` | GitHub Actions workflows, CI scripts, and dependency updates. |
