`cli/` contains a Go CLI scaffold built with Cobra. Product commands are not
implemented yet.

## Local development

Install the Go version declared in `cli/go.mod`. From the repository root, run:

```bash
cd cli
go run . --help
```

This prints the scaffold's help output.

See [API endpoints](/cli/endpoints) for the CLI's HTTP interface status.
