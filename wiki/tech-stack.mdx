## Application

Use Next.js with Bun and TypeScript 7 for frontend development. The existing
`dashboard/` and `web/` applications have not yet migrated to Next.js.

| Layer | Technology | Role |
| --- | --- | --- |
| Frontend | Next.js with TypeScript 7 on Bun | Required framework, language, runtime and toolchain for frontend applications |
| Current web app | React with Vite | Existing single-page application in `dashboard/` |
| Current landing page | Astro with React | Existing static marketing site in `web/` |
| Backend services | Go with Gin | HTTP services and event consumers |
| Database access | GORM | ORM for PostgreSQL access from Go services |

## Data and messaging

| Concern | Technology | Role |
| --- | --- | --- |
| Primary database | Supabase PostgreSQL | Business data and the transactional outbox |
| Authentication | Supabase Auth | Google sign-in, proxied by the `auth` service |
| Cache | Dragonfly | Redis-compatible read cache for the `api` service |
| Event streaming | Apache Kafka on Aiven | Domain events keyed by aggregate ID, with a dead-letter topic |
| Audit store | PostgreSQL on Aiven | Audit log, owned by the `audit` service |
| Job queues | Cloudflare Queues | Prioritized email jobs (`email-high`, `email-low`) |
| Serverless compute | Cloudflare Workers | `email-worker` |
| Transactional email | Resend | Email delivery with idempotency keys |

## Platform and operations

| Concern | Technology | Role |
| --- | --- | --- |
| Observability | OpenTelemetry and Grafana | Traces, metrics and logs through the OpenTelemetry Collector |
| Load testing | Grafana k6 | Virtual-user load tests against the services |
| CI/CD | GitHub Actions | Build, test and deployment workflows |
| Hosting | Fly.io | Deployment of backend services |
