Each sprint lasts two weeks. Fall starts in November 2026; Spring starts on
February 8, 2027 and finishes by the end of April. Work during J-Term is optional
and is not required to complete the nine planned sprints.

| Sprint | Term | Patrick | JZ |
| --- | --- | --- | --- |
| 1 | Fall | Implement the database, authentication, encrypted storage and Web secret creation/retrieval. | Write API tests from supplied cases, prepare fixtures and verify setup commands. |
| 2 | Fall | Implement Web secret updates/deletion, policies, member roles and service access. | Implement the supplied permission test matrix, input-validation tests and revocation cases. |
| 3 | Fall | Complete version history, retrieval tracking and audit logs; integrate the Web MVP and prepare the technical demo. | Add version and audit regression tests; prepare demo data, recordings and fall presentation slides using the agreed template. |
| 4 | Spring | Implement AI reorganization, policy verification, expiration reminders and email delivery. | Test supplied AI examples with fixed responses; add reminder timing, recipient and email-content tests. |
| 5 | Spring | Implement CLI authentication, credential handling, commands and coding agent integration. | Write CLI argument, output and exit-code tests; maintain help text, usage examples and skill documentation. |
| 6 | Spring | Implement browser extension authentication, background communication, interface and save/update integration. | Write message and form-validation tests; verify extension packaging, installation and supplied save/update scenarios. |
| 7 | Spring | Integrate Web, CLI and extension; verify cross-client consistency, complete deployment and freeze features. | Implement supplied cross-client regression scenarios, report reproducible bugs and verify installation instructions. |
| 8 | Spring | Run security, concurrency and performance tests; fix core defects. | Run regressions and usability sessions using the agreed task script; record results and retest fixes. |
| 9 | Spring | Complete final QA, deployment and technical documentation; prepare the technical presentation and rehearse. | Compile test reports and user guides; prepare slides, demo recordings and submission materials using the agreed template, and rehearse. |
