## Archify

Use Archify to create architecture and workflow diagrams from structured input.
It generates standalone HTML diagrams that you can explore and share.

## Figma Console MCP

Use [Figma Console MCP](https://github.com/southleft/figma-console-mcp) to inspect
and edit Figma designs through an AI agent, including editable layers,
components, and variables.

The landing page design lives in
[Keysy — Landing Page](https://www.figma.com/design/SnKNkphMQKvrj8RmPigzao).

## Agent coding principles

[Karpathy Guidelines](https://github.com/multica-ai/andrej-karpathy-skills)
provides the reference for agent coding principles: clarify uncertainty, keep
changes minimal, and verify results.
