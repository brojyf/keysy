`dashboard/` contains the React and TypeScript app built with Vite.

## Local development

Install Bun and Node.js `22.12.0` or later. From the repository root, run:

```bash
cd dashboard
bun install --frozen-lockfile
bun run dev
```

Open the local URL printed by Vite. To check the production build, run
`bun run build` from `dashboard/`.

See [API endpoints](/web/endpoints) for the web app's HTTP interface status.
