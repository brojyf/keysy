Use Next.js with Bun and TypeScript 7 for frontend development. See the
[tech stack](/tech-stack) for the required technologies.

`dashboard/` currently contains the React and TypeScript app built with Vite.
It has not yet migrated to Next.js. The commands below apply to the current app.

## Local development

Install Bun and Node.js `22.12.0` or later. From the repository root, run:

```bash
cd dashboard
bun install --frozen-lockfile
bun run dev
```

Open the local URL printed by Vite. To check the production build, run
`bun run build` from `dashboard/`.

See [API endpoints](/web/endpoints) for the web app's HTTP interface status.
