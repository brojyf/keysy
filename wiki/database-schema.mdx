### Triggers

| Trigger | When | Action |
| --- | --- | --- |
| `create_profile_after_user_insert` | When a user account is created | Creates the user's profile with an initial display name and email address. |

### Scheduled jobs

| Job | Schedule | Action |
| --- | --- | --- |
| `delete-idle-sessions` | Daily | Deletes sessions that have not been refreshed for 30 days. |
| `delete-old-invitations` | Daily | Deletes invitations that expired more than 30 days ago. |

### Functions for the API

| Function | Action |
| --- | --- |
| `public.list_user_sessions(target_user_id)` | Lists the user's active sessions and when they were last used. |
| `public.revoke_user_session(target_user_id, target_session_id)` | Deletes one of the user's sessions. |
| `public.revoke_all_user_sessions(target_user_id)` | Deletes all of the user's sessions. |
