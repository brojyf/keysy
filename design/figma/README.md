## Requested style explorations

Keep the product message and core content consistent so the styles can be
compared. These directions are requested explorations, not an approved final style.

| Style | Direction | Trade-off | Status |
| --- | --- | --- | --- |
| Claymorphism | Rounded, softly inflated surfaces, layered shadows, and restrained pastel blue accents. | Approachable, with more visual weight. | [Desktop and mobile created](https://www.figma.com/design/SnKNkphMQKvrj8RmPigzao?node-id=10-50) |
| Neumorphism | Matching gray backgrounds and surfaces, paired light and dark shadows, and inset details. Keep text and primary actions distinct. | Tactile, but boundaries need care to remain legible. | [Desktop and mobile created](https://www.figma.com/design/SnKNkphMQKvrj8RmPigzao?node-id=10-324) |
| Bento grid | Mixed-size feature panels; give the product preview the largest panel and group access, history, and AI assistance into smaller panels. | Easy to scan, with a busier composition. | [Desktop and mobile created](https://www.figma.com/design/SnKNkphMQKvrj8RmPigzao?node-id=10-598) |
| Light developer | Developer-tool style drawing on Vercel, Supabase, and Cloudflare: grid rails with plus markers, a fading hero grid with soft blue glows, a beam-bordered product preview with floating terminal and AI cards, a feature bento, and a dark code window. Uses the light colors from [Theme](../theme/README.md). | Technical and lively, but has more decorative layers to maintain. CLI commands are illustrative until the CLI defines them. | [Desktop and mobile created](https://www.figma.com/design/SnKNkphMQKvrj8RmPigzao?node-id=17-2499) |
